# VPN Gate

Обёртка над любым Linux-приложением, которая не даёт ему запуститься, если не поднят VPN. Полезно для программ, которым нельзя работать без VPN (торрент-клиенты, мессенджеры, браузеры и т.п.) — блокировка происходит на уровне запуска, а не полагается на то, что вы не забудете включить VPN сами.

Работает с любым VPN-клиентом — WireGuard, Amnezia, OpenVPN, Tailscale и т.д. — проверка идёт по имени сетевого интерфейса, который вы указываете сами.

Есть два равноценных способа управления: **CLI-скрипт** и **GUI-приложение** (GTK4/Adwaita). Оба хранят настройки в одном и том же месте на диске, поэтому ими можно пользоваться как по отдельности, так и вместе.

## Как это работает

1. Установщик находит настоящий бинарник приложения (`REAL_BIN`) и переименовывает/подменяет команду в `~/.local/bin/<app>` на свою обёртку.
2. При запуске обёртка проверяет, поднят ли указанный VPN-интерфейс (по умолчанию `wg0`; опционально — с проверкой, что через него действительно идёт маршрут по умолчанию).
3. Если VPN не подключен — показывается уведомление, событие пишется в журнал, приложение **не запускается** (`exit 126`).
4. Если VPN подключен — обёртка прозрачно передаёт управление настоящему бинарнику (`exec`), включая аргументы командной строки.
5. `.desktop`-файл приложения тоже подменяется, чтобы запуск из меню/дока шёл через защиту.

Всё, что генерируется установщиком — обычные bash-скрипты без внешних зависимостей, так что сама проверка при запуске приложения работает мгновенно и не тянет Python/GTK.

## Требования

- Linux с systemd/XDG-путями (`~/.local/bin`, `~/.local/share/applications`, `~/.config`)
- bash, `ip` (пакет `iproute2`) — для проверки VPN
- Для GUI: `python3-gi`, `gir1.2-gtk-4.0`, `gir1.2-adw-1` (в большинстве современных GNOME-дистрибутивов уже установлены)

## Установка — .deb (Debian/Ubuntu)

```bash
sudo apt install dpkg-dev   # если ещё не установлен
packaging/build-deb.sh
sudo apt install ./packaging/build/vpn-gate_*.deb
```

Пакет ставит `vpn-gate-install` и `vpn-gate-ui` в `/usr/bin`, регистрирует GUI в системном меню и подтягивает все зависимости (`python3-gi`, `gir1.2-gtk-4.0`, `gir1.2-adw-1`). Удаление: `sudo apt remove vpn-gate`.

## Установка защиты — CLI

Из репозитория — `./install-vpn-gate.sh`, после установки `.deb` — команда `vpn-gate-install` (одно и то же, просто разные пути).

```bash
# Найти бинарник автоматически в PATH
./install-vpn-gate.sh telegram-desktop

# Указать путь к бинарнику явно
REAL_BIN=/opt/myapp/bin/myapp ./install-vpn-gate.sh myapp

# Задать интерфейсы VPN (через пробел), если не wg0 — например, amn0 для Amnezia
VPN_IFACES="wg0 amn0" ./install-vpn-gate.sh myapp

# Удалить защиту
./install-vpn-gate.sh --uninstall myapp

# Удалить защиту и конфиг приложения
./install-vpn-gate.sh --uninstall myapp --purge
```

## Установка защиты — GUI

```bash
./vpn-gate-ui        # из репозитория
vpn-gate-ui           # после установки .deb, либо из меню приложений
```

В окне:

- статус VPN с автообновлением и кнопкой ручной проверки;
- список защищённых приложений с быстрым редактированием/удалением;
- **+ Добавить приложение** — установка защиты с автокомплитом имени по `PATH` и выбором бинарника через диалог;
- **Журнал блокировок** — история попыток запуска без VPN;
- **Настройки** — интерфейсы и строгий режим по умолчанию, уведомления, автозапуск.

После первого запуска приложение само добавляет себя в системное меню («VPN Gate»).

## Конфигурация

На каждое защищённое приложение — свой каталог `~/.config/<app>-vpn-gate/`:

| Файл | Назначение |
|---|---|
| `real-bin` | путь к настоящему бинарнику |
| `config` | `VPN_IFACES` (интерфейсы через пробел) и `VPN_STRICT_ROUTE` (0/1 — требовать маршрут через VPN) |

Журнал блокировок запуска общий для всех приложений: `~/.local/state/vpn-gate/events.log` (обрезается автоматически, хранит последние ~300 событий).

## Структура репозитория

```
install-vpn-gate.sh       CLI-установщик (bash, без зависимостей)
vpn-gate-ui               launcher GUI-приложения
vpn_gate_ui/              исходники GUI (GTK4 + libadwaita)
├── core.py                бизнес-логика install/uninstall/list/config
├── vpncheck.py             проверка состояния VPN
├── settings.py             настройки UI, автозапуск
├── window.py                главное окно
├── dialogs.py                диалоги (добавление/редактирование/настройки/журнал)
├── sizing.py                  адаптивные размеры окон под разрешение экрана
└── app.py                     точка входа (single-instance)
packaging/                сборка .deb
├── build-deb.sh            собирает пакет из текущих исходников
└── debian/                 control/postinst/postrm/copyright/changelog/.desktop
```
